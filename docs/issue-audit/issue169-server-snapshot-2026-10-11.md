## Contract

- Every event matches the selected tenant; null selects global events only.
- Declared count matches the supplied complete selection, at most 10,000 events. Overflow returns no partial snapshot. A supplied count alone cannot prove database completeness.
- Explicit UTC timestamps, ordered inclusive capture range ending no later than capture time, seven fractional digits (100 ns), stable canonical GUID ties.
- Nonempty unique event IDs, nonempty optional identity GUIDs, bounded text.
- Immutable event copies and read-only collections.
- Only ID, tenant, timestamp, action, resource type/ID, user, session, correlation and outcome are projected. Description, IP, user agent, error and metadata are omitted. IDs still require an authorized audience; UserId can identify a subject.
- 16 MiB UTF-8 serialization ceiling, with atomic overflow rejection.
- Canonical SHA-256 digest and fixed-time comparison detect modifications against an independently protected expected digest. This does not establish provenance, actor attribution, legal admissibility or clock synchronization.

The public constructor and the Capture factory enforce the same complete validation; no constructor accepts a prevalidated bypass payload. Limits are static read-only properties.

## Verification

45 native C# cases cover these bounds, isolation, safe fields, immutability, timestamps, identifiers, text, digest changes and source failures. Six vectors generated by the accepted Web core (SHA-256 f9c477b7a7cd65eb1f8c0811b178891dee245adc929f2b2bb1dee8e27d50bd99) verify projection compatibility.

The affected-test selector maps the Compliance.Audit module to the historical GameGuild.Audit.UnitTests project and also selects API, Authentication, Authorization and SharedKernel regressions for audit source changes. Three added Node cases verify the alias, security selection and deduplication.

Native results must be attached to the PR. Written cases and static checks do not mean native acceptance. No local SDK/database/app/browser runner was launched; the local incident hold remains active.
