# Reviewed audit reports

This directory contains only deliberately preserved, human-reviewed Quiz +
Grading audits. Raw reports, screenshots, traces, and API snapshots remain in
`apps/web/test-results/quiz-grading-validation/` and are ignored by Git.

A preserved report must state its commit, selected case IDs, environment,
reviewer, evidence references, and any changes made to
`../capability-status.md`.
