# Authorization cache observability deployment

The API exports authorization-cache metrics through its OpenTelemetry meter when
`OpenTelemetry:Enabled` is `true`. Configure an absolute HTTP or HTTPS OTLP
endpoint, or enable the console exporter for local diagnostics. Supported OTLP
protocol values are `http/protobuf` and `grpc`. If OpenTelemetry is enabled
without a configured exporter, or with an invalid endpoint or protocol, the API
fails at startup instead of silently dropping telemetry.

## Local Compose stack

The optional Compose overlay starts the API, an OpenTelemetry Collector, Prometheus,
and Alertmanager. Prometheus loads the cache alert rules from
`authorization-cache-alerts.yml`, scrapes the Collector, and forwards firing alerts
to Alertmanager. The Prometheus and Alertmanager web interfaces are bound to
localhost only. The local Alertmanager receiver is intentionally empty; configure a
real notification receiver in the deployment-specific Alertmanager configuration
before relying on alerts for on-call response.

```powershell
docker compose -f compose.yaml -f compose.authorization-observability.yaml --profile app --profile authorization-observability up -d api otel-collector prometheus alertmanager
```

Set `AUTHORIZATION_OTLP_HTTP_PORT`, `AUTHORIZATION_PROMETHEUS_PORT`, and
`AUTHORIZATION_ALERTMANAGER_PORT` to change the local observability ports. Standard
Compose keeps telemetry disabled by default; enable it only with a reachable OTLP
endpoint, or use this overlay to start the bundled local Collector.

## Coolify or another external deployment

The Coolify Compose file passes these variables through to the API:

| Variable | Default | Purpose |
| --- | --- | --- |
| `OPENTELEMETRY_ENABLED` | `false` | Enables API traces and metrics. |
| `OPENTELEMETRY_OTLP_ENDPOINT` | empty | Absolute endpoint for the configured collector. |
| `OPENTELEMETRY_OTLP_PROTOCOL` | `http/protobuf` | OTLP transport (`http/protobuf` or `grpc`). |
| `OPENTELEMETRY_SERVICE_NAME` | `GameGuild.API` | Service identity in telemetry. |
| `OPENTELEMETRY_SERVICE_INSTANCE_ID` | generated by API | Stable instance identity when supplied by the orchestrator. |
| `OPENTELEMETRY_CONSOLE_EXPORTER_ENABLED` | `false` | Enables console output for local diagnostics. |
| `OPENTELEMETRY_INCLUDE_SQL_STATEMENTS` | `false` | Controls SQL statement capture in traces. |

When `OPENTELEMETRY_ENABLED=true`, set `OPENTELEMETRY_OTLP_ENDPOINT` to the
deployment collector. Load `docs/api/authorization-cache-alerts.yml` into the
deployment Prometheus rule files and configure its Alertmanager receiver for the
service's real notification channel. The local Compose receiver only verifies
Prometheus-to-Alertmanager handoff; it does not send external notifications.
